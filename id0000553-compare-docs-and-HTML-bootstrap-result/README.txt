
DESCRIPTION: this script compare 2 files and show the result in a nice Bootstrap HTML page with a checkbox to mark all task to do. Also remove all possible white spaces, break lines, empty lines, and break the text of both files when the script find a dot. The goal is remove all styles and focus only in check character text comparison.

EXECUTE: on your terminal go inside the folder script and execute: python3 app.py
The file index.html will be generate and also open in your default browser if not, open yourself the index.html with double click.

Software: Python3, Bootsrap5

LIBRARIES: to open direct in your browser you need to install this libraries, is optional you can do manually by double click on index.htmlsudo update-desktop-database
